# THE OVERMIND PROTOCOL - Mission Control Dashboard

A Streamlit-based web interface for real-time system management and goal adjustment for THE OVERMIND PROTOCOL.

## Features

- Real-time portfolio tracking
- Dynamic goal management
- Trading activity monitoring
- System status dashboard
- Interactive visualizations with Plotly

## Installation

```bash
uv sync
```

## Usage

```bash
streamlit run app.py
```

## Dependencies

- Streamlit for web interface
- Plotly for interactive charts
- Pandas for data processing
- HTTPX for API communication
- Redis for DragonflyDB integration

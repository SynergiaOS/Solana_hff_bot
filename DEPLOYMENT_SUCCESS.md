## 🚀 DEPLOYMENT INSTRUCTIONS

### 📋 **PREREQUISITES:**
1. **Rust** - Latest stable version
2. **Python 3.12+** - With pip/uv package manager
3. **Docker** - For DragonflyDB and monitoring
4. **Solana CLI** - For wallet operations
5. **Git** - For version control

### 🔧 **SETUP PROCESS:**
```bash
# 1. Clone repository
git clone https://github.com/SynergiaOS/Solana_hff_bot.git
cd Solana_hff_bot

# 2. Setup environment
cp .env.template .env
# Edit .env with your credentials

# 3. Install dependencies
cargo build --release
pip install -r requirements.txt

# 4. Start services
docker-compose up -d

# 5. Launch THE OVERMIND PROTOCOL
cargo run --profile contabo
```

### 🔐 **SECURITY SETUP:**
```bash
# 1. Create paper backup
python3 scripts/extract_private_key_for_paper.py

# 2. Secure environment variables
export SNIPER_WALLET_PRIVATE_KEY="your_private_key_here"

# 3. Verify security
python3 scripts/security_audit.py
```
